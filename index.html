    Cérebro avançado ✨

    Opcional. Sem isso, o Koa funciona normalmente.

    Com uma chave da API do Claude, o Koa continua aprendendo do mesmo jeito, mas fala de forma mais natural. Ele só usa o que aprendeu com você.

    Privacidade e custo

    A chave fica guardada só neste aparelho e é enviada apenas para api.anthropic.com. A cada mensagem, o Koa envia o que aprendeu e as últimas mensagens da conversa para a API do Claude. O backup exportado não inclui a chave.

    O uso da API é cobrado na conta dona da chave. Crie a chave em console.anthropic.com e defina um limite de gastos baixo. Quem mexer no celular desbloqueado consegue ver a chave.
